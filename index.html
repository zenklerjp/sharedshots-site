Set it up before
the first guest arrives.

An album takes about a minute to make. Build it a few days ahead, put the code where people will look, and the night takes care of itself.

  1. A few days ahead

    Make the album

    Name it, set the date, and leave it waiting. A free album lasts 3 months from the day you create it, so a few days early is right and a few months early is not.

  2. The day before

    Print the code

    Every album carries a six-character code with a QR code beside it. Put them on table cards, the bar, the back of the invite.

  3. As people arrive

    Point at the table

    Guests scan with the camera already in their hand, or type the code at sharedshots.site. Adding photos from a phone browser needs no download.
